  • 01辞書 0 B の UTF-8 コードポイント N-gram 64-bit 指紋

    UTF-8 の文字境界から漢字・カタカナの 1 文字特徴と 2 文字バイグラムを直接ハッシュし、語彙辞書ゼロのまま高密度にならない約 25% 活性の 64-bit 特徴ベクトルへ変換します。

  • 02実数 Teacher（2,176 乗算）からラベルなし日本語経由で KL 蒸留

    同じ初期配線・160 LUT 構成（第1層 N=4 WARP + 2/3層 N=2）の 2 生徒を比較します。Scratch はラベル付き 24 文のみ CE 学習するのに対し、KL 蒸留生徒は Teacher がラベルなし日本語ログ 32 文へ付けた柔らかい確率分布まで丸ごと吸収して未知文の汎化精度を引き上げます。

  • 03論理合成＋64 並列ビットスライスで数十 ns/文の超高速ルーティング

    蒸留後の回路に DCE / CSE / 定数畳み込みをかけて数十ゲートへ圧縮。1 文字打つたびに乗算 0 回で応答するキャッシュ常駐エッジ分類器になります。
