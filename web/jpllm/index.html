1. チャット対応＆4 モードを 1 つの極小論理ゲート LLM に統合

マルチターン会話 [会話]（U: ... / A: ... の文脈保持）と、3 つの日本語スタイル変換（[X訳]・[関西]・[津軽]）を 1 本の純 Kizu バイトレベル BPE モデルへ統合しています。

2. 強化版 段階蒸留（L0 → L0b → L3-C + N=4 WARP LUT + MUX Value Skip）

Apache 2.0 の Qwen3-4B-Instruct で生成した 5,033 件（740 KB）のマルチターン会話＆変換コーパスに対し、Apple M4 Max 上の純 Kizu Metal GPU カーネルで L0（実数 4 層 d=192 Transformer, PPL 11.56）を学習。 そこから Warm-Start＋応答トークン重視の KL 蒸留で L0b（FFN 4,608 個 N=4 WARP LUT, PPL 11.40 で実数 Teacher 超え）を構築し、さらに L0b の離散 LUT を逆ウォルシュ・アダマール変換で引き継いで Hardware MUX Value Skip 付き L3-C（6,912 LUT・ブロック乗算 0 回・PPL 19.22）へ結晶化しました。

3. ブラウザ完結 WASM 推論（UTF-8 状態制約 + Top-p 0.85 + 反復ペナルティ）

すべての推論は 636 KB の統合 Kizu WASM（サーバー通信・WebGPU 不要）で動作し、UTF-8 継続バイトの状態機械により文字化け（）を構造上ゼロに抑えています。L3-C は XNOR-popcount と 1-hot ハードウェア MUX（1.84 ms/fwd）で実行されます。
