1. 新旗艦 v3（Griffith-JP-Base v1 + Chat SFT：12 層・98,304 N=4 LUT）

日本語 Wikipedia＋FineWeb-2 JA＋EN 技術文書の 3,385 万トークン（純 Kizu 互換 BPE 8,192） を NVIDIA A100 上で事前学習した汎用日本語ベース Griffith-JP-Base v1（d=512・6 層×2 ループ＝実質 12 層・GQA 8Q/2KV・RoPE）を構築。 FFN の 2,477 万乗算を 0 乗算 FWHT（高速ウォルシュ・アダマール変換）＋ 2-bit 温度計 ＋ 98,304 個の離散 N=4 WARP-LUT（196,608 実効評価/tok・FFN 乗算 0 回） へ KL 蒸留し、さらに 4 モード会話データ＋汎用日本語リプレイで特化しました（検証 PPL 8.41・9.21 MB int8 .glgpt v3）。

2. v2 段階蒸留ラダー（M4 Max 純 Kizu Metal GPU：L0 → L0b → L3-C）

Apple M4 Max 上の純 Kizu Metal GPU カーネルで学習した 4 層 d=192・BPE 1,280 モデル群もそのまま比較可能。L0（実数 PPL 11.56）→ L0b（4,608 LUT, PPL 11.40）→ L3-C（6,912 LUT・1-hot ハードウェア MUX・全ブロック乗算 0 回・1.07 MB）への結晶化をリアルタイムに見比べられます。

3. ブラウザ完結 Pure Kizu WASM（インクリメンタル KV-Cache + UTF-8 状態制約）

全モデルが 890 KB の統合 Kizu WASM（サーバー通信・WebGPU 不要）で動作し、v3 は自動 Prefix KV-Cache により単一スレッド WASM で 約 118 tok/s（ネイティブ LLVM では 182 tok/s）、PyTorch 参照ロジットと誤差 < 0.0005 の一致を検証済み。UTF-8 継続バイト状態機械により文字化け（）を構造上ゼロに抑えています。
