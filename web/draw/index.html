  • 01固定回路ではなく、ブラウザ内でゼロから学習している

    このページの app.wasm には学習済みモデルではなく、純 Kizu 製の微分可能 LUT 学習器（WARP + Gumbel-ST / Softmax + AdamW）が入っています。「データ編集」で完全にオリジナルの図形を描き足して学習しても、その場で解く回路が生まれます。

  • 02灰色の確率雲から論理ゲートが「結晶化」する

    学習前は 120 個のゲートがすべて曖昧な連続確率ですが、勾配降下が進むと各ゲートが XOR / XNOR / AND / NOR などの純粋な論理演算へ尖っていきます。純計算は数十 ms で終わるため、観察モードではあえて 3.2 秒かけて推移を見やすく再生しています。

  • 03論理合成で不要・重複ゲートを削ぎ落とし、重みを 0 B にする

    学習後に 4 パスの論理合成（定数畳み込み・パススルー／反転吸収・CSE・DCE）を走らせると、生き残った数十個のゲートだけで乗算 0 回の 64 並列ビット演算推論（数 ns/回）ができます。

  • 04次の Lab 02 へ：このまま Transformer（LLM）にスケールする

    同じ Kizu 微分可能 LUT 基盤で構築した LogicLadderGPT（FFN・QKV・Attention まで論理ゲート＋MUX 化した極小 LLM）を次の ladder/ として追加予定です。
